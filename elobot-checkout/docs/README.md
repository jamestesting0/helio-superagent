# EloBot documentation

These guides record the conventions and testing lessons from the Elo Final work.

- [Discord testing in Mozilla Firefox](discord-qa.md): the three test accounts, beta channels, interaction checks and evidence.
- [Bot UI conventions](bot-ui.md): embeds, emojis, pagination and controls.
- [Writing bot messages](copy-style.md): concise copy and examples of information to remove.
- [Base fingerprint search](base-fingerprints.md): the existing feature documentation.

Read [AGENTS.md](../AGENTS.md) before changing code. The [Final plan](../.omo/plans/elo-final-system.md) owns the feature requirements; later user decisions about commands and presentation take precedence.

Recorded on 2026-10-10. The latest testing preference is no browser tests. The Firefox guide describes how to conduct a future requested walkthrough; writing these docs does not reopen the browser or run the bot.

Historical results and screenshots are in the [Final UI review](../.omo/evidence/elo-final/ui-review.md). The [emoji update review](../.omo/evidence/elo-final/emoji-copy-2026-10-03/review.md) records automated verification without browser testing. Earlier screenshots can show superseded copy; neither report proves that accounts, roles, fixtures or processes are still available today.
